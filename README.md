# Basic TypeScript

A browser-ready TypeScript example covering:

- Primitive types: `string`, `number`, `boolean`, and `undefined`
- Type aliases and union types
- Interfaces for strongly typed objects
- Typed arrays
- Typed functions and return values
- Compilation from TypeScript to browser JavaScript

## Run

```bash
npm install
npm run build
```

Open `index.html` in Chrome after building. For a local server, run:

```bash
npx serve .
```

Then open the URL shown in the terminal. The page loads `dist/main.js`, which is generated from `src/main.ts`.
